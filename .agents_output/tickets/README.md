# ARA Implementation Tickets

Tickets are numbered in a suggested implementation order. Each ticket is small
enough to implement and review independently. A ticket may be started only when
all listed dependencies are complete.

Each implementation commit must follow these repository rules:

- Start the commit summary with a verb.
- Wrap every commit-description line at 80 characters.
- Supply separate commit message paragraphs with repeated `git commit -m`
  arguments instead of embedding newline escape sequences.

The architecture source of truth is `../architecture.md`.
