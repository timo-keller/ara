# 001 - Create project scaffolding

## Goal

Create the top-level backend, frontend, and deployment structure without
implementing application features.

## Scope

- Add the agreed repository directories.
- Add root documentation and ignore rules.
- Document local prerequisites and standard commands.
- Reserve locations for Compose and deployment configuration.

## Acceptance Criteria

- The repository layout matches the architecture document.
- Generated files, local databases, secrets, and certificates are ignored.
- A new developer can identify where backend, frontend, and deployment code
  belongs.

## Dependencies

None.
