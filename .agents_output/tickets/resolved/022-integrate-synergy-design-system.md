# 022 - Integrate Synergy Design System

## Goal

Use Synergy as the frontend component and visual foundation.

## Scope

- Install the Synergy Angular, component, token, font, and asset packages.
- Apply the chosen Synergy theme globally.
- Configure the Synergy MCP server over stdio for development.
- Add a representative accessible component smoke test.

## Acceptance Criteria

- Angular renders Synergy components without runtime warnings.
- Fonts, tokens, and icons load from local application assets.
- MCP defaults target the Angular framework.
- The production image does not contain the MCP server.
