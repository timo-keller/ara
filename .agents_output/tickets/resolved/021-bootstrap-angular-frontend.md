# 021 - Bootstrap Angular frontend

## Goal

Create a production-buildable Angular application with quality tooling.

## Scope

- Generate the Angular workspace and application.
- Configure strict TypeScript, linting, formatting, and unit tests.
- Add environment-independent runtime API paths.
- Establish feature-oriented source directories and routing.

## Acceptance Criteria

- Development and production builds succeed.
- Linting and unit tests pass.
- The application uses relative `/api` and `/auth` URLs.
- No deployment secret is included in the frontend build.
